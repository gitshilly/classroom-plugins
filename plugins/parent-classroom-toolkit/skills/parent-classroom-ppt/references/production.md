# 制作规范与决策

## 主线与内容取舍

先确定核心问题或故事线，逐页内容与活动推进理解。旁支冷知识仅在服务目标时保留；超时或信息过密时先删非核心内容，不用增加页数解决取舍。重大取舍提供理由由用户决定，常规精简在已授权范围内执行。

## 事实、图像与课堂

- 给知识主张保留页码、来源位置、适用范围、核验状态；科学、历史、动物、安全知识查可靠依据。图中器物、结构、动作、颜色含义单列，不用文字来源替整图背书。素材使用依据与知识来源分别记录。
- 关键事实无法确认则补证据、改准确简图或删除非必要细节；不以“AI示意图”免除准确性。儿童只看图、听一句话可能形成的结论也要检查，少数示例不能暗示全部类别。
- 亮点来自真实反常识、观察线索和任务，不靠夸张编造。孩子见过相关绘本时，优先设计比较、解释、预测和应用，不只重复百科名称。
- 提问服务本页目标：要解释用途就问作用或原因，不停在一眼可认的“这是什么”。互动写清观察什么、如何参与、等待多久、讲者怎样接话、何时揭晓；口头、翻页和点击揭晓分别标明。
- 时长包括介绍、口播、观察、操作、讨论、儿童分享、条件反馈、翻页和感谢；备课说明不计入口播。不把括号内纠错口播当零秒，不重复计算互动。提供可压缩环节；静态估算、独自试讲、模拟回答和真实课堂分开。

## 视觉设计

一套像同一展馆：字体、色彩角色、笔触、光线、边距和互动组件连贯，每页按教学目的换构图。不要把浅黄背景、固定标题栏、左字右图当默认。图文优先大幅场景、上下组织、图下注释和留白；适合的对比可以分栏。

先保存视觉方案卡和逐页布局分配。可用场景、观察放大、知识图解、对比、时间线、问答、任务挑战等；连续四五页雷同是检查信号，不为变化随意换画风。画面吸引力与留白并存，不堆贴纸，不用白底小图代替设计。重要文字不盖关键图像。

默认新课16:9，局部修改保持原尺寸。主题决定色彩与画风，不强制黏土、手绘、小芽或统一配色。已认可封面与内页的特征写入保留清单。成交案例只能提供观察与灵感，不证明画风导致销售。

标题、正文、题目、选项、答案及可修改图注用PPT原生文字。HTML路线导出无字场景作为背景，再叠加原生对象；整页截图不能冒充可编辑PPT。图片比例、关键结构、裁切、对比度与后排可读性都要看最终PPT渲染。

## 教案为正式交付必备

后续新课完整教学包默认独立交付《教案.docx》（可编辑Word），按需另附PDF；工作稿或Markdown不冒充Word。用户明确指定其他格式或只要求大纲/样张时遵从。旧课局部修改不自动补教案；用户要求补教案或更新完整包时纳入，按实际PPT与讲稿编写，不虚构已有材料。

教案说明“整堂课为什么这样安排、怎样组织”；逐字稿说明“下一句怎么说”；备课与操作说明承载设备、预试、材料规格、资料来源和详细排查；救场话术供现场速查。教案保留独立可读的目标、准备摘要、流程和关键回应，细节可指向对应文件章节，不重复粘贴整份逐字稿或多份时间表。主时间表放在教案，其他文件引用或保持同版本一致。

按实际课型组织，不硬凑页数或学术术语，可从 [教案模板](../assets/教案模板.md) 起草：

1. 基本信息：主题、年级/班龄、讲者身份、目标时长及估算/试讲状态、对应PPT文件与版本。未知班级人数等不编造，影响组织时澄清或明确假设。
2. 学习目标与关键理解：具体、适龄，至少一项可观察的儿童表现；指出本课关键点和可能难点，避免空泛目标。
3. 课前准备：设备、必要道具及数量依据、座位/分组、儿童经验或前置知识，安全注意；无特殊材料如实写明。详细规格和预试指向备课说明。
4. 活动流程：各环节的实际PPT页码、目的、预计用时、家长组织与关键提问、孩子观察/操作/表达、可能回应及判断依据、揭晓方式、观察点与过渡。开放题写合理回答范围，不硬设唯一答案；提示答案先后与PPT及逐字稿相符。
5. 控时与调整：汇总口播、等待、操作、分享、反馈、过渡和缓冲；指明可压缩环节及跳转页，不能删必要安全内容或使故事断裂。
6. 收束与观察：如何通过孩子的解释、选择理由、操作或作品判断目标是否达成；延伸仅在必要时提供，课堂外内容不计入授课时长。课后记录留空或标“待实施后填写”，不得编写已发生的课堂反应。

家长进课堂用非专业讲者能看懂的组织语言。教师公开课继续按专属规则提供详细教案、说课稿等，不被通用模板削弱。班会按项目要求将成人处理建议设独立可查章节或文件。

教案与PPT/备注/TXT从同一确认框架编写，最终页序确定后回填真实页码。逐环节核对目标、题目、答案依据、孩子任务、组织方式、材料、时间和揭晓；改活动/页序/答案时同步受影响文件及展示。不能为丰富教案添加课堂中不存在的必做活动或课件未含的功能；可选延伸须单列并说明新增准备。

生成DOCX时使用可用文档技能，实际打开或渲染检查标题、表格跨页、字号、换行、裁切和空白；确实无法生成或检查时标明缺项/限制，不以改扩展名、空模板或文件存在替代完成。内部来源哈希和核验记录放工作单，不挤入家长教案正文。

## 上台稿与配套

同一底稿输出每页PPT备注和UTF-8 TXT：`第N页｜标题`，自然短句口播、必要过渡、紧邻发生位置的【短提示】。提问后先等待/操作再回应，不提前漏答案。PPT备注的上台稿部分与TXT一致；额外备课区明确隔开。

每页末尾两行实际空白，末页同样保留。上台稿不堆“建议用时/备课来源/制作原因”等栏目。备课说明独立承载详细操作安排、道具数量依据、预试、组织方式、来源和详细排查。现场必要安全口令、停止条件及简短成功/失败分支仍贴着操作。

独立《课堂救场话术.txt》至少覆盖不会回答、无人应答、抢答、时间不足、答错；实验/音视频按需补失败情境。每项写情况、可直接说的一两句话和下一动作；按真实页码与主题写，不虚构课堂反应，不承诺无法兑现的后续回答。

班会另按项目规则提供独立可查找的成人处理建议，不用救场话术替代。未使用的道具、附件不硬塞，交付和商品描述只能列实际文件。

## 无配套验收技能时的最小交接检查

实际渲染最终PPT全页并逐页看，检查带页码全览；代码和HTML预览不能替代。按实际关系读取PPT备注，与TXT核对页序、内容、提示、两行空白。核对第2页介绍和末页谢谢、全部图片及附件；对照独立教案逐环节检查真实页码、活动、答案、材料、揭晓和总时长，并查看DOCX实际版面。独立副本试改文字，按适用要求实测放映和揭晓；未实测独立记录。用户当次选择静态验收时写明范围、替代证据和限制，不推广成永久例外。

修正后更新相关PPT、教案、备注、TXT、逐页图、总览及已有相关展示素材。事实错误、关键不可读、误导图像或严重缺失修正后再作为正式成品。真实试讲未做不一概阻断交付，也不声称已实测。
