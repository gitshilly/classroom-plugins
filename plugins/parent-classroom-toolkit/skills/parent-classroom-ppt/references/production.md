# 制作规范与决策

## 主线与内容取舍

先确定核心问题或故事线，逐页内容与活动推进理解。旁支冷知识仅在服务目标时保留；超时或信息过密时先删非核心内容，不用增加页数解决取舍。重大取舍提供理由由用户决定，常规精简在已授权范围内执行。

## 事实、图像与课堂

- 给知识主张保留页码、来源位置、适用范围、核验状态；科学、历史、动物、安全知识查可靠依据。图中器物、结构、动作、颜色含义单列，不用文字来源替整图背书。素材使用依据与知识来源分别记录。
- 关键事实无法确认则补证据、改准确简图或删除非必要细节；不以“AI示意图”免除准确性。儿童只看图、听一句话可能形成的结论也要检查，少数示例不能暗示全部类别。
- 亮点来自真实反常识、观察线索和任务，不靠夸张编造。孩子见过相关绘本时，优先设计比较、解释、预测和应用，不只重复百科名称。
- 提问服务本页目标：要解释用途就问作用或原因，不停在一眼可认的“这是什么”。互动写清观察什么、如何参与、等待多久、讲者怎样接话、何时揭晓；口头、翻页和点击揭晓分别标明。
- 时长包括介绍、口播、观察、操作、讨论、儿童分享、条件反馈、翻页和感谢；备课说明不计入口播。不把括号内纠错口播当零秒，不重复计算互动。提供可压缩环节；静态估算、独自试讲、模拟回答和真实课堂分开。

## 视觉设计

一套像同一展馆：字体、色彩角色、笔触、光线、边距和互动组件连贯，每页按教学目的换构图。不要把浅黄背景、固定标题栏、左字右图当默认。图文优先大幅场景、上下组织、图下注释和留白；适合的对比可以分栏。

先保存视觉方案卡和逐页布局分配。可用场景、观察放大、知识图解、对比、时间线、问答、任务挑战等；连续四五页雷同是检查信号，不为变化随意换画风。画面吸引力与留白并存，不堆贴纸，不用白底小图代替设计。重要文字不盖关键图像。

默认新课16:9，局部修改保持原尺寸。主题决定色彩与画风，不强制黏土、手绘、小芽或统一配色。已认可封面与内页的特征写入保留清单。成交案例只能提供观察与灵感，不证明画风导致销售。

标题、正文、题目、选项、答案及可修改图注用PPT原生文字。HTML路线导出无字场景作为背景，再叠加原生对象；整页截图不能冒充可编辑PPT。图片比例、关键结构、裁切、对比度与后排可读性都要看最终PPT渲染。

## 上台稿与配套

同一底稿输出每页PPT备注和UTF-8 TXT：`第N页｜标题`，自然短句口播、必要过渡、紧邻发生位置的【短提示】。提问后先等待/操作再回应，不提前漏答案。PPT备注的上台稿部分与TXT一致；额外备课区明确隔开。

每页末尾两行实际空白，末页同样保留。上台稿不堆“建议用时/备课来源/制作原因”等栏目。备课说明独立承载时间表、道具数量依据、预试、组织方式、来源和详细排查。现场必要安全口令、停止条件及简短成功/失败分支仍贴着操作。

独立《课堂救场话术.txt》至少覆盖不会回答、无人应答、抢答、时间不足、答错；实验/音视频按需补失败情境。每项写情况、可直接说的一两句话和下一动作；按真实页码与主题写，不虚构课堂反应，不承诺无法兑现的后续回答。

班会另按项目规则提供独立可查找的成人处理建议，不用救场话术替代。未使用的道具、附件不硬塞，交付和商品描述只能列实际文件。

## 无配套验收技能时的最小交接检查

实际渲染最终PPT全页并逐页看，检查带页码全览；代码和HTML预览不能替代。按实际关系读取PPT备注，与TXT核对页序、内容、提示、两行空白。核对第2页介绍和末页谢谢、全部图片及附件。独立副本试改文字，按适用要求实测放映和揭晓；未实测独立记录。用户当次选择静态验收时写明范围、替代证据和限制，不推广成永久例外。

修正后更新相关PPT、备注、TXT、逐页图、总览及已有相关展示素材。事实错误、关键不可读、误导图像或严重缺失修正后再作为正式成品。真实试讲未做不一概阻断交付，也不声称已实测。
