# 投入判断与多轮共创

固定质量标准默认执行，课程设计通过多轮交流确定。AI承担产品经理辅助、课程设计辅助和质量审查；用户决定关键选题、投入、课程取舍与最终验收。自然提出新课即可启动，不要求用户重复粘贴提示词。

## 制作前的合并检查卡

“上架前检查卡”用于完整制作前判断是否值得投入，不代表成品已通过发布检查。沿用 [选题四格卡模板](../assets/选题四格卡模板.md)，一次记录：

- 四格：主题；购买者与孩子、实际场景；一句话真实钩子；孩子具体观察或动作及理解目标。
- 需求依据：真实咨询、同类销售或搜索观察等，写来源、日期和适用范围；未取得与AI推测单列，阅读收藏不能当订单，不虚构市场规模。
- 投入判断：可复用资产、与已有课的区别、主要新增插画/考据/互动/附件工作、最可能返工处；给带依据的粗略工作量或复杂度，不作无依据工期承诺。
- AI推荐：进入框架共创、先补证据或缩小范围、暂缓；说明理由和最小下一步，不以机械分数或固定销量门槛代替判断。
- 用户决定、投入边界、尚存未知项和确认依据。

先带入已确认信息，只追问影响决定的关键缺口，优先每轮一至三项；提供可比较候选及推荐理由。不得将AI建议当用户确认。四格任一未确认，只讨论候选和可行性，不展开完整大纲、样张、PPT或商品素材。

市场证据不足不等于没有需求；说明不确定性，用户在四格明确后可决定承担有限投入继续。确认后保存为课程目录的 `选题四格卡.md`，并沿用同一课件工作单记录阶段，不要求用户重复填表。非销售用途的需求依据按实际教学需要记录，不强迫证明商业需求。

## 共创与执行节奏

1. 投入与四格确认后，给出核心目标、故事或问题主线、活动与时间预算，由用户确认框架及重要取舍。
2. 用本课真实内容验证代表页，合并确认视觉；已有适用批准有效，不逐页审批。
3. 样张获准后连续完成PPT、独立教案、备注、逐字稿与适用附件。排版、错字和授权内常规修正直接处理；受众、主题、核心目标、主要活动或画风实质变化时，仅对齐受影响部分。
4. AI先修复检查发现的可处理问题，再提供成品、检查摘要和未覆盖项供用户最终验收。检查通过不等于用户已验收，也不等于可自动发布。

每轮简要说明已确定内容、AI推荐与理由、确需用户决定的问题。共性要求内化到实际检查，过程记录不变成用户作业。旧课局部修改与重写笔记不重新立项；仅对实质改变的四格重新对齐。

## 固定标准的落实

- 视觉：字体、色彩逻辑、画风与组件统一，按教学目的变化场景和构图；全览检查连续页面，不能靠换底色充当设计。
- 互动：适合实际年级和组织条件，明确观察、动作、等待、回应与揭晓；要理解用途就问用途，不包装显而易见的认物题。
- 内容：各环节推进同一主线；旁支冷知识服务目标，不以知识点或页数堆价值。
- 讲稿：自然口播、提示紧邻操作、先等待再回应、过渡顺畅，备课与上台稿分开，配必要救场话术。
- 控时：明确时长优先；无另约定时默认含互动和缓冲30分钟以内，框架写明。超时优先删非核心环节，估算和实测分开。
- 展示：笔记图用故事封面、真实问题互动和家长讲法说明价值；商品图以真实PPT封面和内页为主。末图复用既有通用交付图，产品具体信息写在文案中。原页不改，内容不足不凑页，销售效果不能保证；详细执行由交付技能承接。
