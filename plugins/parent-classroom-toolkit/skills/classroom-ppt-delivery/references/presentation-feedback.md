# 真实展示与反馈

涉及小红书时，在当前项目读取docs/小红书运营基础规则.md、docs/当前账号运营执行规则.md及docs/小红书内容与电子资料经营研究补充.md。没有对应账号资料时报告缺口，不套另一个账号的数据或承诺。其他平台按用户指定规则；需要现行平台或法律要求时核验可靠来源，不将旧草稿当现行许可。

按真实内容组织搜索词、具体趣味问题、课堂任务和交付说明。当前项目惯例为三个不超过20字候选标题（推荐一个）、自然正文、3—5个相关话题；20字是账号内部标准，不冒充平台最新限制。无实际课堂不编孩子反应，无订单不编销量或评价。

商品/笔记任务默认同时给文案与生成好的首图（当次只要文字除外）。首图优先用最终课件素材，与普通知识页和互动页品质一致；用户指定直接用封面时遵从。中间图直接用最终PPT真实渲染，不AI重生成仿内页；裁切/局部放大另标明。记录上传图序、版本、PPT实际页码、主题及选用理由。

默认按“有故事感的封面 → 有趣问题 → 课堂互动 → 家长可讲 → 资料完整”组织8张：1张故事封面、5张精选问题与互动、1张家长讲法、1张本产品具体交付清单；当次指定其他数量时遵从，真实内容不足不虚构凑页。这是展示策略，不是成交保证。有项目规范 `docs/笔记图故事场景与真实内页出图规范.md` 时读取适用补充。

内页保持原文字、答案、图像、颜色、比例、布局和交互表现；外层可加标题、边框、阴影和拼接，不能遮挡原内容，不为宣传改PPT。家长讲法来自真实稿件和操作；最后写清实际页数、年级、时长依据、讲稿、互动、准备材料及文件格式，通用交付说明只能补充，不能代替本产品清单。

附件默认列用户自行截图的真实文件和具体章节；页码未知不猜；无需时明说。只有最终教学包实际包含且已核对的教案才能写成卖点；新规范不代表所有旧商品已有教案，格式必须如实。没有真实附件不能写成卖点。当前平台电子资源性质、交付方式及退换边界按最新规则确认，不用历史模板排除法定权益。

反馈按版本和页码收集原话与证据，区分文件故障、知识/图像、课堂可用性、视觉偏好、展示描述和外部因素。缺信息先做可做的定位；不把猜测说成复现。视觉偏好不自动触发全套改版。修复后记录PPT/稿件/图/包/宣传受影响项和复查；是否联系买家或替换已发文件按用户授权执行。

经验沉淀到可复用组件时写教学目标、输入、布局、操作、反馈、时长、来源页和验证状态。历史成交与视觉相关不等于因果；“文件验证”“真实课堂验证”分开。未产生真实反馈时可提供空白反馈单，不能称已完成售后效果验证。
