# 验收与工具

## 固定标准与用户验收

共性标准不反复询问，按实际任务范围检查并绑定页码、证据、问题、动作和复查结论：

- 视觉连贯且构图有变化，连续页面不机械重复；不能把换底色当变化。
- 内容围绕明确主线，互动适合实际年级和组织条件，说明观察什么、做什么、为什么这样问、讲者怎样回应；不能仅因有选择题就称适龄。
- 上台稿能连续念、过渡顺畅、等待先于答案，备课分离，救场话术贴合本课。
- 时长按当前确认核算；新课未另约定时以含互动与缓冲30分钟以内为设计目标，不把此默认强加到旧课。超时处理非核心内容，重大取舍回到用户决定。
- 本轮涉及宣传时，用真实原页、实际互动、家长讲法及具体交付证明价值；不从质量检查推出销量或课堂效果。

新课交接读取已有四格卡和投入决定，缺记录如实指出、不伪造确认；旧课技术核对、局部修正和宣传不重新立项。修正常规问题无需重复审批，实质范围变化只对齐受影响部分。工作单分别记录AI检查结果与用户最终验收依据；用户未验收不能代填通过。制作前投入判断不能替代真正发布前的产品一致性及适用规则检查。

## 分项核验

- 最终PPT实际渲染全部页并逐页看，带页码总览检查连续布局、风格、信息密度与衔接。已有最终版本绑定的渲染可复用；旧图片存在或像素可解码不等于绑定本版本。
- 第2页介绍及末页谢谢依课型和当次要求检查；页图、总览、备注与TXT对应。教师公开课按其专属规则处理。
- 知识/图像核验依据独立记录，主张来源不自动证明整图或使用许可。重新检查受影响事实和图像，不机械复核全部旧内容。
- 备注按PPT关系读取body，排除页码占位。TXT逐页口播、提示、顺序与备注上台稿一致，保留两行空白。若备注有隔开的额外备课区，先明确提取边界；不能把全文严格比对的失败当成口播不一致。
- 标题正文等应原生可编辑；结构存在、程序改字、鼠标点选编辑是不同证据。最终PPT放映验证实际动画、音视频、链接与揭晓；口头/翻页揭晓如实描述。
- 控时计入介绍、实际口播、等待、儿童回答、操作、纠错和翻页；备课内容不计。条件分支不要因在括号内而被当作零时长。真实试讲未做不一概阻断，但估算不能叫实测。
- 按实际需求核对PPTX、备注、UTF-8上台TXT、全部逐页图、总览、备课说明、独立救场话术及其他承诺附件。文件存在检查不替代顺读与可用性。

## 随包脚本

定位当前skill目录为SKILL，使用已有Python。`check_delivery_v2.py` 依赖同目录 `check_delivery.py` 和Pillow；先检查可用运行库，无需安装新服务。脚本只读产品输入，写指定报告，不操作放映窗口。

复制 `assets/核验配置模板.json` 到课件研究/制作资料目录，填写真实路径。`workspace_root`相对配置文件；不要把修改时间当在售确认。空模板不能直接跑。

```text
python -X utf8 SKILL/scripts/check_delivery_v2.py 配置.json --output 研究目录/文件核验.json
```

需要人类可读结果时，建立项目登记JSON：
```json
{"output_folder":"核验结果","cases":{"lesson":{"title":"课件名","config":"配置.json","work_order":"课件工作单.json","scope_note":"本轮检查范围"}}}
```
路径相对登记文件目录，输出必须在该研究目录内；工作单baseline提供pptx_sha256和confirmed_by_user，版本不符不会借用其确认。
```text
python -X utf8 SKILL/scripts/delivery_assistant.py --registry 项目登记.json --case lesson --date YYYY-MM-DD
```
日期填写实际检查日。输出检查结果、待处理问题、文件清单、完整核验和运行记录。当前只核验，不自动组装ZIP或发布。

退出码0=配置内文件检查通过；2=实际差异；3=已检查项通过但有证据缺项；其他错误需查运行环境/格式。外层shell可能只返回通用非零码，以报告实际exit_code和检查明细定位。无报告不能当通过。

## 格式与限制

工具按实际presentation关系解析页序。TXT页头支持`第01页｜`或`第1页|`，保留段内空白；旧混合稿`---`分隔符需明确适配，不能不加说明地删差异。图片当前支持两位页码PNG。ZIP包裹目录用明确zip_prefix，不自动猜或解压输入。

底稿为数组page/notes/seconds/wait_seconds；缺底稿或时间字段不猜定时长。程序只数主线汉字、排除括号，条件口播需人工复核；估算工具不能代替完整控时。

manifest支持顶层sha256；其他真实格式需适配，不制造假的历史清单。缺独立底稿、ZIP等标未检查，不用PPT反向抄底稿自比通过。expected_sha256仅锁定本次文件，不能证明渲染或买家版本。

工具允许历史样本不追溯两空行；新制作/明确改稿可设require_two_blank_lines=true。缺证据并不全部是发布硬门槛，按实际约定判断；严重事实与可读性问题仍必须修正。

可运行 `python -m unittest discover -s SKILL/scripts -p "test_*.py" -v` 检查差异检出、版本隔离和缺项不冒充通过。它不测试课堂效果。
