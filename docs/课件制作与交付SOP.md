# 课件制作与交付 SOP

这是我在家长进课堂课件制作中逐步整理的要求，也是一份持续修改的清单。可以结合自己的年级、讲者、设备和实际用途采用；没有实际检查过的项目，不写成已经通过。

我希望达到的使用标准是：**家长扫一眼，就知道下一句说什么、下一步做什么。**

## 1. 先确认内容与样式

**需求明确 → 逐页大纲 → 代表性样张 → 整套制作。**

先把主题、使用对象和场景、有趣且真实的记忆钩子、最容易参与的互动讲清楚，再讨论框架。大纲确定后，用场景、知识、互动等有代表性的页面验证视觉；已有适用且确认过的样张可以复用。整套制作沿用确认过的方向，修改时说清保留什么、这轮改什么。

## 2. 定稿后同步配套文件

**PPT、备注、逐字稿、互动答案和附件应属于同一最终版本。**

### 上台逐字稿

独立提供 UTF-8 TXT，按最终 PPT 页码排列，包含页码和标题、能直接说出口的自然口播、提问与等待、回应与揭晓、翻页过渡及必要操作提示。每页讲稿结束后留两行空白，便于阅读与补充。PPT 备注中的上台稿应与 TXT 一致。

### 教案、备课与操作说明

后续新课的完整交付包含独立教案，包含课后反思与调整的填写框架；未实际讲过的课不编造反思结果。备课说明交代时间分配、道具、预试、课堂组织和详细操作；上台稿只保留现场需要的简短提示。

### 课堂救场话术

结合本课互动，至少准备：孩子提问但讲者不会回答、没人回应、兴奋抢答、时间不够和回答错误。按「遇到什么情况 → 能直接说的一两句话 → 下一步做什么」编写。有实验、道具、音视频时再补对应情况。

## 3. 检查最终 PPT

| 项目 | 检查内容 |
|---|---|
| 内容与事实 | 知识、图像细节、题目及答案有依据，页面与讲稿一致。 |
| 页面与视觉 | 没有文字溢出、遮挡、错误裁切，关键内容清楚可读。 |
| 互动与放映 | 揭晓顺序正确；实际点击验证需要的动画与交互。 |
| 讲稿与使用 | 口播自然，提问、等待、回应衔接顺畅，操作提示出现在对应位置。 |
| 版本一致性 | 页码、备注、TXT、教案和附件都对应同一最终 PPT。 |

检查时打开最终 PPTX；静态截图检查与实际放映分别记录。未验证的项目如实说明。小学家长课堂还需核对独立介绍页、明确的感谢页，并把开场、互动和收尾计入时长；其他讲者或课堂类型按实际需求安排。

## 4. 从最终版导图并打包

从验收后的最终 PPT 导出全部逐页图片，按页码命名；制作覆盖全部页面、标注页码的总览图。核对数量、顺序、版本与来源。

完整新课交付时核对：

**可播放、可编辑的 PPTX（含备注）＋独立 TXT 逐字稿＋教案＋备课与操作说明＋课堂救场话术＋全部逐页图＋带页码总览＋本课需要的附件。**

只要求大纲、样张或旧课局部修改时，按当次范围交付；发现缺项应说明，不能为了清单齐全编造文件或检查结果。

## 5. 需要上架素材时，再准备宣传

按需提供：商品或笔记文案 → 首图 → 真实内页选用顺序 → 附件截图 → 通用交付说明图。内页与附件展示应对应实际文件；页数、功能、包含内容与最终交付包一致。制作课件本身不自动包含发布商品或联系买家。

## 继续改，继续积累

先做起来，遇到问题就去查、去问。把这一次解决的问题和下一次还会用到的要求留下来，再继续做。
